## ▶ 패드/폰에서 실행하는 법

### 방법 A — raw.githack.com (저장소가 공개일 때, 가장 쉬움)
패드 사파리에서 아래 주소를 엽니다(설치·설정 0):
```
https://raw.githack.com/jeon-byeong-ik/justin_1w/claude/lizard-gauge-game-rc6boh/web/index.html
```
> 저장소가 **비공개면 이 방법은 안 됩니다** → 방법 B 사용.

### 방법 B — GitHub Pages (한 번만 설정하면 깔끔한 URL)
1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch** → Branch를 `claude/lizard-gauge-game-rc6boh`, 폴더 `/web`(또는 루트)로 지정 후 Save
   - `/web`을 못 고르면, `index.html`을 저장소 루트나 `/docs`로 옮겨 지정
3. 잠시 후 발급되는 `https://<아이디>.github.io/justin_1w/` 주소를 패드에서 열기

### 방법 C — 파일로 바로 열기
`index.html`을 패드의 **파일 앱**에 저장한 뒤, 파일을 길게 눌러 브라우저로 열기.
(외부 의존성이 없어 인터넷 없이도 동작합니다.)

## 🎮 조작 (터치 우선)
- **타이틀:** 화면의 버튼을 탭 — 혼자하기 / 둘이 대결 / 상점 / 무한 챌린지 / 리더보드 / 일일 도전
- **발사:** ① 화면 연타로 파워 충전 → ② 탭으로 각도 확정(45° 초록 스위트스팟=퍼펙트) → ③ 결과
- **둘이 대결:** 화면 **왼쪽 절반 = P1**, **오른쪽 절반 = P2** (자기 차례에만 반응)
- **메뉴/결과:** 좌상단 **✕ 타이틀**로 복귀
- 데스크톱 키보드도 지원: `1~6` 모드, `A`/`L` 2인, `Space` 발사, `Esc` 타이틀

## 💾 저장
진척·기록은 브라우저 **localStorage**에 저장됩니다(기기·브라우저별로 보관).

## 🖼️ 캐릭터 이미지 (본인 사진으로 교체)
타이틀의 **`🖼️ 캐릭터 이미지`** 버튼 → 진화 단계별(도마뱀/모토마/미라이돈) **`사진 선택`** →
패드 사진 보관함(또는 PC 파일)에서 이미지를 고르면 그 캐릭터로 플레이됩니다.

- 이미지는 **이 기기 브라우저(localStorage)에만** 저장됩니다 — **저장소·공유 URL에는 포함되지 않습니다.**
- 즉, 본인 기기에서만 보이며, 저작권 자산을 공개 배포하지 않습니다(개인 사용에 적합).
- `전체 지우기`로 도형 캐릭터로 되돌릴 수 있습니다.
- 배경이 투명한 PNG를 쓰면 더 깔끔합니다(흰 배경이면 흰 사각형째 보임).
