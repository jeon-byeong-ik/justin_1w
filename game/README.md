# 🦎 도마뱀 발사! — Godot 프로젝트 (M0 프로토타입)

> 제작: **justin** · 엔진: **Godot 4.3+** · 현재 단계: **M0~M4 (핵심·저장·진화연출/사운드·2인대결·지역/상점)**

게이지를 시간 안에 채워 도마뱀을 멀리 날리는 게임. 본 폴더는 실행 가능한 Godot 프로젝트입니다.

---

## ▶ 실행 방법
1. [Godot 4.3 이상](https://godotengine.org/download) 설치 (Standard / GDScript 버전)
2. Godot 실행 → **Import** → 이 `game/` 폴더의 `project.godot` 선택
3. 상단 ▶(Run Project, F5) 클릭

> ⚠️ 이 프로토타입은 작성 환경에 Godot이 없어 **에디터 실행 검증은 아직 못 했습니다.**
> 파일은 Godot 4 규격에 맞춰 작성했으며, 처음 열 때 오류가 나면 알려 주세요(바로 수정).

## 🎮 조작
**타이틀:** `[1]`/왼쪽 = 혼자하기 · `[2]`/오른쪽 = 둘이 대결 · `[3]` 상점 · `[4]` 무한 챌린지 · `[5]` 리더보드 · `Esc` = 타이틀로
**상점:** `[1]` 가벼운 비늘(공기저항↓) · `[2]` 강화 코어(파워↑) — 에너지로 구매(영구) · `Esc` 뒤로
**무한 챌린지:** 무풍 조건에서 단발 비거리 도전 → 기록이 로컬 리더보드(상위 10)에 저장 · `[탭]` 다시 · `[Esc]` 타이틀

**혼자하기 (SOLO)** — 탭 / `Space` / 클릭으로 모든 동작
| 단계 | 조작 | 설명 |
|------|------|------|
| 시작 | 탭 | READY → 충전 시작 |
| 1. 파워 | 연타 | 3초 안에 파워 게이지를 채움 (흰 선=100%, 넘으면 오버차지 위험) |
| 2. 각도 | 탭 1회 | 왕복하는 빨간 바늘을 **초록 스위트스팟(45°)** 에서 확정 → 발사 |
| 결과 | 탭 | 비거리·퍼펙트·에너지 확인 → 다시하기 (기록 자동 저장) |

**둘이 대결 (VERSUS)** — 턴제, 3판 2선승
| 플레이어 | 키 | 화면 |
|----------|-----|------|
| P1 | `A` 연타 | 왼쪽 절반 탭 |
| P2 | `L` 연타 | 오른쪽 절반 탭 |
- P1이 한 번 발사 → P2가 한 번 발사 → 비거리 비교 → 라운드 승자 → 먼저 2승하면 매치 승리
- 자기 차례에만 입력이 먹습니다(상대 키 무시). 매치 후 `[탭]` 리매치 / `[Esc]` 타이틀

## 🧬 구현된 것
- **핵심 루프(2단계):** 충전(연타·시간제한·자연감소) → 각도 타이밍 → 비행 → 결과
- **발사 공식** (`LaunchFormula.gd`, `contracts/launch-formula.md` 구현, 바람 반영)
- **진화 시스템** (`Evolution.gd`): 누적 에너지로 1→2→3단계, 능력치·색 변화, 스프라이트 교체
- **저장 (M1)** (`SaveData.gd`): 지갑·누적에너지·최고기록·누적거리·상점강화를 `user://save.json`에 자동 저장
- **진화 연출 (M2)**: 점멸+확대 펄스 애니메이션(`EVOLVE` 상태, 탭으로 건너뛰기)
- **사운드 (M2)** (`AudioManager.gd`): 연타·발사·퍼펙트·착지·진화·승리 효과음을 **코드로 즉석 합성**(에셋 파일 0)
- **2인 턴제 대결 (M3)**: 모드 선택, 턴 관리, 3판 2선승, 입력 키 분리, 리매치
- **스토리 지역 (M4)** (`Region.gd`): 4개 지역, 누적 비거리로 해금, 지역별 하늘색·바람
- **상점 (M4)**: 가벼운 비늘(공기저항↓)·강화 코어(파워↑) 영구 강화 구매
- **무한 챌린지 + 리더보드 (M4)** (`Leaderboard.gd`): 무풍 단발 도전, 상위 10 기록 로컬 저장, 순위 표시
- 터치/마우스/키보드 입력, 진화 단계별 사용자 이미지 로딩(`assets/stageN.*`)

## 📂 구조
```
game/
├─ project.godot          # 프로젝트 설정 (메인 씬·해상도)
├─ icon.svg
├─ scenes/Main.tscn       # 루트 씬
└─ scripts/
   ├─ Main.gd             # 게임 루프 & 상태머신 (솔로/대결/상점/진화연출)
   ├─ LaunchFormula.gd    # 발사 거리 계산 (순수 로직)
   ├─ Evolution.gd        # 진화 단계·능력치 (순수 로직)
   ├─ Region.gd           # 스토리 지역·바람 (순수 로직)
   ├─ Leaderboard.gd      # 무한 챌린지 리더보드 (순수 로직)
   ├─ SaveData.gd         # 로컬 저장/불러오기 (user://save.json)
   └─ AudioManager.gd     # 절차적 효과음 합성 (에셋 불필요)
```
