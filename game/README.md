# 🦎 도마뱀 발사! — Godot 프로젝트 (M0 프로토타입)

> 제작: **justin** · 엔진: **Godot 4.3+** · 현재 단계: **M0 (핵심 루프 프로토타입)**

게이지를 시간 안에 채워 도마뱀을 멀리 날리는 게임. 본 폴더는 실행 가능한 Godot 프로젝트입니다.

---

## ▶ 실행 방법
1. [Godot 4.3 이상](https://godotengine.org/download) 설치 (Standard / GDScript 버전)
2. Godot 실행 → **Import** → 이 `game/` 폴더의 `project.godot` 선택
3. 상단 ▶(Run Project, F5) 클릭

> ⚠️ 이 프로토타입은 작성 환경에 Godot이 없어 **에디터 실행 검증은 아직 못 했습니다.**
> 파일은 Godot 4 규격에 맞춰 작성했으며, 처음 열 때 오류가 나면 알려 주세요(바로 수정).

## 🎮 조작 (M0: 1인 플레이)
| 단계 | 조작 | 설명 |
|------|------|------|
| 시작 | 탭 / `Space` / 클릭 | READY → 충전 시작 |
| 1. 파워 | 연타 | 3초 안에 파워 게이지를 채움 (흰 선=100%, 넘으면 오버차지 위험) |
| 2. 각도 | 탭 1회 | 왕복하는 빨간 바늘을 **초록 스위트스팟(45°)** 에서 확정 → 발사 |
| 결과 | 탭 | 비거리·퍼펙트·에너지 확인 → 다시하기 |

## 🧬 구현된 것 (M0 + 각도 단계)
- 2단계 발사 루프: 충전(연타·시간제한·자연감소) → 각도 타이밍 → 비행 → 결과
- 발사 거리 공식 (`LaunchFormula.gd`, `contracts/launch-formula.md` 구현)
- 진화 시스템 (`Evolution.gd`): 누적 에너지로 리지→모토마→미라이돈, 능력치·색 변화
- 누적 에너지·최고 기록·진화 단계 HUD 표시
- 터치/마우스/키보드 입력 지원

## 🚧 아직 없는 것 (다음 마일스톤)
- 저장(localStorage 대응: `user://` JSON) — *재실행 시 기록 초기화됨*
- 2인 턴제 대결 (M3)
- 진화 연출, 사운드, 스토리 지역, 상점 (M2·M4)
- 스프라이트 아트 (현재는 도형으로 임시 표현)
