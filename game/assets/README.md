# 캐릭터 스프라이트 넣는 곳

게임은 이 폴더의 이미지 파일을 **자동으로 불러와** 도마뱀 자리에 그립니다.
파일이 없으면 도형(초록 원) 플레이스홀더로 대체됩니다.

## 파일 이름 규칙
진화 단계별로 아래 이름의 PNG를 이 폴더에 넣으세요.

| 파일명 | 진화 단계 |
|--------|-----------|
| `stage0.png` | 1단계 (리지 / 도마뱀) |
| `stage1.png` | 2단계 (모토마) |
| `stage2.png` | 3단계 (미라이돈) |

- 권장: 배경이 투명한 PNG, 정사각형에 가깝게(예: 256×256). 화면에서 약 96px로 표시됩니다.
- 파일을 넣은 뒤 Godot 에디터로 한 번 임포트되면(폴더를 열면 자동) 실행 시 반영됩니다.

## 이미지 준비에 대한 안내
포켓몬(모토마/미라이돈 등) 공식 아트·스프라이트는 게임프리크/닌텐도의 **저작물**입니다.
개인 학습·비공개 용도로 본인이 직접 구한 이미지를 위 이름으로 이 폴더에 넣어 사용할 수 있으나,
**해당 이미지를 이 저장소에 커밋하거나 외부에 배포하지 않는 것**을 권장합니다
(`.gitignore`에 `assets/*.png`를 추가해두면 실수로 커밋되는 것을 막을 수 있습니다).
공개 배포가 목표라면 직접 제작한 오리지널 아트를 사용하세요.
